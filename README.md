# RegApp Java Web Application

A Java Servlet based registration web application developed using Java Servlets, HTML5, and Apache Tomcat.

This project demonstrates user registration handling, servlet communication, form processing, and dynamic response generation in a web environment.

---

## Features

- User registration form
- Multi-servlet processing
- HTML form handling
- Dynamic response generation
- Java Servlet backend integration

---

## Technologies Used

- Java
- Servlet API
- HTML5
- Apache Tomcat

---

## Project Structure

```text
REGAPP/
│
├── Register.html
│
└── WEB-INF/
    ├── web.xml
    └── classes/
        ├── RegistrationServletOne.java
        └── RegistrationServletTwo.java
```

---

## How It Works

1. User enters registration details
2. Form data is submitted to the servlet
3. Servlet processes the request
4. Registration data is handled dynamically
5. Response/result is displayed in browser

---

## How to Run

1. Install Apache Tomcat
2. Copy project folder into Tomcat `webapps`
3. Start Tomcat server
4. Open browser:

```text
http://localhost:8080/REGAPP
```
